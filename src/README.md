# 🤖 3D Web Experience Using Algoryx Community

## 📌 Project Overview

This project was developed as part of the **Algoryx Internship - Task 3**.

The objective of this project is to build a modern, responsive website by integrating a 3D asset downloaded from the **Algoryx Community** platform. The website provides an interactive user experience with smooth animations and a professional UI.

---

## 🚀 Features

- Responsive Navigation Bar
- Modern Hero Section
- Interactive 3D Robot Model
- Smooth Animations
- Responsive Design
- Professional UI
- Footer Section
- Optimized Performance

---

## 🛠 Technologies Used

- React.js
- Vite
- Three.js
- React Three Fiber
- React Three Drei
- CSS3
- JavaScript

---

## 🤖 3D Asset

The 3D Robot model used in this project was downloaded from the **Algoryx Community** platform and integrated using React Three Fiber.

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/yamuna2211/Task3algoryx.git
```

Go to the project

```bash
cd Task3algoryx
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```
